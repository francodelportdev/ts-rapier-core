How it's built

  1. Create the game

    await Game.create(canvas) loads Rapier, which is WebAssembly, and then creates the physics world. That's why it's async and you can't use new Game().

  2. Add the entities

    Each entity creates its own body in the physics world. addEntity() adds it to the game loop so that it gets updated and drawn. Units are meters, with the Y axis pointing up and the origin at the center of the canvas.

    EntityBody typeBehavior
    Ground / PlatformfixedNever moves.
    BoxdynamicAffected by gravity, collisions and impulses.
    PlayerkinematicMoved by code. It pushes the boxes, and nothing pushes it.

  3. Add your own controls

    box.applyImpulse(0, 5) changes the box's velocity instantly. The box weighs 1 kg, so an impulse of 5 N·s adds 5 m/s upwards.

  4. Start the loop

    game.start() runs physics at a fixed 60 steps per second, whatever your screen's refresh rate. Each step calls update() on every entity and then world.step(). Each frame then calls draw().

Full source: src/main.ts

To use it in your own project, run bun add @francodelportdev/rapier-engine, add <canvas id="game"> to your HTML, and paste this code.

Player

Move & jump

Player is a platformer character. Rapier's kinematic character controller handles collisions: it detects the ground, steps over small bumps and pushes dynamic bodies out of the way.

Click to play
  • ← → or A D Move
  • Space, ↑ or W Jump (hold to jump higher)

How it works

  1. Acceleration, not instant speed

    Each step, the horizontal speed moves towards speed at acceleration m/s², and back to 0 at deceleration m/s². In the air, both are multiplied by airControl, so you can steer a jump without stopping dead.

  2. Gravity and jump

    A kinematic body ignores the world's gravity, so the player applies its own (gravity, 40 m/s² by default, for snappy jumps). The jump speed is √(2 · gravity · jumpHeight), which is exactly the speed needed to reach jumpHeight.

  3. Variable height

    If you release the key while still rising, the upward speed is multiplied by jumpCut once. A tap gives a short hop, and holding the key gives the full jump.

  4. Coyote time and jump buffer

    Two small timers make jumping feel fair. Coyote time lets you jump for coyoteTime seconds after walking off a ledge. The jump buffer remembers a press for jumpBuffer seconds, so pressing just before landing still jumps.

All of them are optional. Pass them as new Player(world, { ... }).

Player

Double jump

Set maxJumps: 2 and the player can jump once more in mid-air. The platform here is too high for a single jump.

Click to play
  • ← → Move
  • Space Jump, then Space again in the air

How it works

  • maxJumps is the number of jumps available before landing. 1 is a normal jump, 2 is a double jump, and 3 or more lets you keep jumping.
  • Every jump in the air resets the upward speed to the full jump speed, so it reaches the same height as a jump from the ground.
  • Walking off a ledge without jumping uses up the ground jump, so you only get the air jumps. Within coyote time, a jump still counts as a ground jump.
  • Landing restores every jump.

Player

Dash

A short horizontal burst in the direction the player is facing. The gap here is too wide for a jump, so jump and then dash in the air.

Click to play
  • ← → Move
  • Space Jump
  • Shift or X Dash

How it works

  • The dash is off by default. Turn it on with dash: true to use the defaults, or pass an object to tune it.
  • During the dash, the horizontal speed is fixed at dash.speed and gravity is paused, so the player moves in a straight line. When it ends, the player continues at normal top speed.
  • You can dash any time on the ground, and once per jump in the air. cooldown sets the minimum time between dashes.
  • The player turns lighter green while dashing, and its eye shows which way it's facing.
OptionDefaultDescription
dash.speed20m/s during the dash.
dash.duration0.15Seconds. The distance covered is speed × duration, 3 m by default.
dash.cooldown0.4Seconds before the next dash.
