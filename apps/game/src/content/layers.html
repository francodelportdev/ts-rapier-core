Collision layers

Layers decide who collides with whom. Here, the player pushes the red balls and walks through the blue boxes, and the two colors ignore each other. Flip the switches to change the rules while it runs.

How it works

  1. Name your layers

    defineLayers(["world", "player", "enemy"]) gives each name a bit. There can be up to 16, and TypeScript checks the names you use.

  2. Layer and mask

    Each entity has layers, what it is, and a mask, what it collides with. layers.filter("player", ["world", "enemy"]) builds both.

  3. Both sides must agree

    Two entities collide only if each one's layer is in the other's mask. If one side leaves the other out, they pass through each other.

  4. Apply it

    Pass collision as an option to Player, Platform and Shape, or as the fourth argument of Box. On any entity, entity.setCollision(filter) changes it at any time, and getCollision() reads it. By default, an entity is in every layer and collides with everything.

const layers = defineLayers(["world", "player", "enemy"]);

new Platform(world, { x: 0, y: -5, width: 20, collision: layers.filter("world", ["player", "enemy"]) });
new Player(world, { collision: layers.filter("player", ["world", "enemy"]) });

The player respects its filter everywhere: walking, standing, wall slides and pushing boxes. A Sensor detects by layer too. In a level, collision works in platforms, shapes and player, as plain numbers.
