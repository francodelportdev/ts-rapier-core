A 2D game engine for the web

rapier-engine is a TypeScript engine built on Rapier physics. You write entities as classes, and it runs the physics, the input and the drawing on a canvas. Every page of this site is a playable demo with its source code. Try this one: push the boxes off the platform.

Use it in your project

It isn't on npm yet. Build it and pack it into a file, from a copy of the repository:

cd packages/core
bun run build && bun pm pack    # writes rapier-engine-0.3.0.tgz

Then add that file to your project with bun add /path/to/rapier-engine-0.3.0.tgz, and start a game on a canvas:

import { Box, Game, Ground, Player } from "rapier-engine";

const game = await Game.create(document.querySelector("canvas")!);
const world = game.getWorld();
game.addEntity(new Ground(world));
game.addEntity(new Player(world));
game.addEntity(new Box(world, 0, 5));
game.start();

How this demo is built

  1. Create the game

    await Game.create(canvas) loads Rapier, which is WebAssembly, and then creates the physics world. That's why it's async and you can't use new Game().

  2. Add the entities

    Each entity creates its own body in the physics world. addEntity() adds it to the game loop so that it gets updated and drawn. Units are meters, with the Y axis pointing up and the origin at the center of the canvas.

    EntityBody typeBehavior
    Ground / PlatformfixedNever moves.
    BoxdynamicAffected by gravity, collisions and impulses.
    PlayerkinematicMoved by code. It pushes the boxes, and nothing pushes it.

  3. Add your own controls

    box.applyImpulse(0, 5) changes the box's velocity instantly. The box weighs 1 kg, so an impulse of 5 N·s adds 5 m/s upwards.

  4. Start the loop

    game.start() runs physics at a fixed 60 steps per second, whatever your screen's refresh rate. Each step calls update() on every entity and then world.step(). Each frame then calls draw().

Each demo is one function that receives a canvas. To use one in your own project, paste the body of the function. ui and Demo only belong to this site: they show the labels over the canvas.
