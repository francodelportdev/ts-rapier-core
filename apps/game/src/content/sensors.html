Sensors & triggers

A sensor is an area nothing collides with, which tells you what's inside it. Push a box onto the yellow plate to open the gate, then jump over the box and go through. Watch the blue radar count the boxes around you.

Sensor

const plate = new Sensor(world, { x: 2, y: -4.25, geometry: { type: "box", width: 2, height: 0.5 } });

plate.on("enter", ({ entity }) => console.log("in", entity));
plate.on("exit", ({ entity }) => console.log("out", entity));

It takes any Shape geometry except a polyline, plus x, y and angle.

OptionDefaultDescription
follow, offsetnoneKeeps the sensor on an entity, for a detection radius or an attack hitbox. That entity isn't detected.
filtereverythingA function that decides what counts, such as (e) => e instanceof Box.
collisionevery layerDetect by layer. Both sides must agree, as with collisions.
detectFixedfalseAlso detect fixed entities, such as platforms.
oncefalseTurn off after the first enter. Whatever was inside then gets an exit.
colorinvisibleDraws the area, translucent.

Methods: getInside(), isOccupied(), setEnabled(on), and on circular sensors setRadius(r) and getRadius(). A sensor only works once it's added to the game, because it checks during update(). Destroying an entity inside it fires exit. Listeners can safely remove entities. Sensors never detect each other.

Trigger

Trigger is the simple case: a rectangle or circle that watches one entity. Level goals, coins and hazards are triggers.

const goal = new Trigger(world, { x: 9, y: -3.5, width: 1, height: 2, target: player, once: true });
goal.on("enter", () => win());

From a collider to its entity

entityOf(world, collider) returns the entity a Rapier collider belongs to, which helps when you make your own Rapier queries.
