Graphics & sound

Audio

Effects and music at game.audio. Click the game to turn the sound on, then jump, dash and collect the coins. The coin is a real sound file, and the other sounds are made by code.

  • Shift Dash

Playing sounds

await game.audio.load("jump", "/jump.ogg");   // from a file
game.audio.synth("coin", { frequency: [988, 1319], duration: 0.08 });  // from code

player.on("jump", () => game.audio.play("jump"));
game.audio.play("coin", { volume: 0.5, rate: 1.5 });

game.audio.playMusic("theme", { fade: 1 });
game.audio.stopMusic({ fade: 1 });

  1. Unlocking

    Browsers block sound until the player interacts with the page. The first click, touch or key on the canvas unlocks it. Until then, effects are skipped and music waits. game.audio.state is "running" once it's unlocked.

  2. Effects

    play(name, { volume, rate }) returns a handle with stop(). rate changes the speed and the pitch: 2 is an octave up. Slightly different rates make repeated sounds less tiring.

  3. Music

    playMusic(name, { volume, fade }) loops a sound, replacing the current music. pauseMusic() and resumeMusic() hold it and continue from the same point. It keeps playing across scene changes, so stop it yourself when needed.

  4. Volumes

    masterVolume, effectsVolume and musicVolume go from 0 to 1, and isMuted silences everything.

Sounds from code

synth optionDefaultDescription
wave"square""sine", "square", "triangle", "sawtooth" or "noise".
frequency440Pitch in Hz, or a list of notes played in sequence.
endFrequencynoneSlides each note to this pitch.
duration0.15Seconds per note.
volume0.50 to 1.

Unknown names throw an error. Where Web Audio isn't available, everything silently does nothing. All sound stops while the page is hidden. Destroying the game closes its audio. Paths in load() are normal URLs: with Vite, files in public/ are served from the root.
