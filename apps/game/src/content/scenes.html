Scenes & levels

A game is more than one screen. Scenes switch between menus and levels, and levels are plain data, so they can live in JSON files.

  • Enter Start or continue
  • ← → Move
  • Space Jump
  • R Restart the scene

Scenes

Extend Scene, build your entities in onEnter(data), and register a factory, so every visit starts fresh.

class Menu extends Scene {
  onEnter() { /* add entities */ }
  update() { /* runs every physics step */ }
  draw(ctx, width, height) { /* menus and HUDs, in pixels */ }
}

game.scenes.add("menu", () => new Menu());
game.scenes.go("menu");

  1. Changing scene

    game.scenes.go(name, { data, fade }) is safe anywhere, even in an event listener: the change waits for the end of the physics step. With fade, the screen fades to black, the physics freezes, and the new scene fades in. While a change is under way, further calls are ignored.

  2. Cleaning up

    Leaving a scene calls onExit() and then game.clear(), which removes every entity and resets the camera, the gravity and the kill plane. this.game.on() inside onEnter() ends with the scene. For anything else, use this.listen(off), or clean up in onExit().

  3. Restarting

    game.scenes.restart() enters the current scene again with the same data. The change event tells you about every change.

Levels

new LevelScene(data, { next }) builds a level from its data, follows the player with the camera and handles the goal. On reaching the goal, it goes to the next scene and passes it the stats: { coins, totalCoins, deaths, time }.

FieldRequiredDescription
nameyesShown in errors and available as scene.level.name.
boundsyes{ minX, maxX, minY, maxY }. The camera stays inside it, and falling 5 m below it counts as a death.
spawnyesWhere the player starts and respawns.
goalyesAn area: { x, y, width, height }.
platformsnoPlatform options, including oneWay.
shapesnoShape options, for ramps, hills and more.
boxesnoPositions of pushable boxes.
hazardsnoAreas that send the player back to the spawn.
coinsnoPositions of coins.
playernoPlayer options for this level, such as { "maxJumps": 2 }.
gravitynoWorld gravity, in m/s², for boxes and dynamic shapes. The player has its own: use player: { gravity }.

LevelScene checks the required fields and throws an error naming the level and the problem. Other fields aren't checked.

Goals, hazards and coins are built with Trigger.
