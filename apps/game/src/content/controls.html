Controls

Choose what triggers each action, for the keyboard and a gamepad. Press + Add, then the key or the pad control you want, or × to remove one. Your choice applies to every demo here and stays saved in this browser.

In your game

const controls = new Controls();

controls.add("jump", { type: "key", code: "KeyJ" });
controls.add("right", { type: "axis", axis: 5, direction: 1 });
controls.remove("jump", { type: "key", code: "Space" });
controls.applyTo(game);

localStorage.setItem("controls", JSON.stringify(controls));   // save
controls.load(JSON.parse(localStorage.getItem("controls")));  // restore

  1. Actions

    The actions are left, right, jump, dash and down. Each one has a list of inputs: { type: "key", code }, { type: "button", button } or { type: "axis", axis, direction }.

  2. Applying them

    applyTo(game) works below Player, so every player follows it, also those a scene creates. Call it again after a change: controls.on("change", () => controls.applyTo(game)).

  3. Conflicts

    An input can only belong to one action. Adding it to another one moves it.

  4. Saving

    toJSON() gives plain data, and load() restores it, skipping anything invalid. reset() goes back to the engine's defaults.

Keys outside the actions, such as Enter here, work as usual. On-screen buttons always work. To find a pad's numbers, use the Gamepad page. The bindings are shared by all games on a page.
