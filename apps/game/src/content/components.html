Components

Instead of writing a new class for every combination, add small behaviors to any entity. Here, the player gets health, a health bar and sparks, and red shapes patrol and hurt it. Switch the health bar off to remove that component while the game runs.

  • ← → Move
  • Space Jump (×2)

Using components

const health = player.add(new Health(5));

player.get(Health);      // the component, or undefined
player.has(Health);      // true
player.remove(Health);   // detaches it

An entity can have one component of each class. Adding a second one of the same class throws an error.

Writing your own

class Spin extends Component {
  update(dt) {
    const body = this.entity.getBody();
    body.setRotation(body.rotation() + dt, true);
  }
}

crate.add(new Spin());
MethodWhen it runs
onAttach()On being added. this.entity is ready.
update(dt)Every physics step, after the entity's own update(). dt is in seconds.
draw(ctx, scale, centerX, centerY)After the entity is drawn.
onDetach()On being removed, or when the entity is destroyed. Undo what onAttach() set up.
onCollisionStart(other) / onCollisionEnd(other)When its entity starts or stops touching another one (see Collisions).

Components can find each other with this.entity.get(Health). entity.getBody() gives the Rapier body, and entity.getGame() gives the game once the entity has been added. Components only update inside a Game.

Included components

ComponentDescription
new Health(max, { invulnerableTime })damage(n), heal(n), reset(), value, isDead and isInvulnerable. Events change and death. It doesn't remove the entity: you decide what death means.
new Patrol(points, speed)Moves a kinematic entity along the points and back. speed can be changed at any time. A player standing on it rides along, so it also works as a moving platform.
new Lifetime(seconds)Removes the entity after that time. For projectiles and effects.
