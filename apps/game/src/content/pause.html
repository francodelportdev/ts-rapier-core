Pause

Freeze the game and keep drawing it, so a pause menu can show on top.

  • P or Esc Pause and resume
  • The button at the top right does the same, with the mouse or a finger

Pausing

canvas.addEventListener("keydown", (e) => {
  if (e.code === "Escape" && !e.repeat) game.isPaused() ? game.resume() : game.pause();
});

Toggle it from a keydown handler, which runs once per press. Reading the key every frame would toggle it on every frame while the key is held.

While paused
StopsPhysics steps, entity and component updates, animations, camera moves and scene fades.
Keeps goingDrawing, the frame event, and the scene's draw(), which is where this demo draws its menu.
InputKeys, the pointer and pads work, for the menu. A tap lasts one frame, and the one that resumes doesn't reach the game.
MusicKeeps playing. Also call game.audio.pauseMusic() for silence.

The time spent paused isn't simulated afterwards, so nothing jumps ahead on resume. game.on("pause") and game.on("resume") run on each change. game.stop() is different: it stops drawing too.
