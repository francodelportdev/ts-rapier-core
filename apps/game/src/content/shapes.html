Engine

Geometry

Shape is a physics body with any geometry: boxes, circles, capsules, ramps, convex polygons and polylines. Use fixed shapes to build levels, and dynamic ones for objects that fall, roll and bounce.

  • ← → Move (walk up the ramp, try the steep slab)
  • Space Jump (×2)
  • Click to drop a shape
  • 1–5 Choose circle, box, triangle, hexagon or capsule

Geometry

Sizes are in meters. Points are relative to the shape's position.

geometryDescription
{ type: "box", width, height }A rectangle, centered on the position.
{ type: "circle", radius }A circle. A line from its center shows it rolling.
{ type: "capsule", radius, height }A vertical segment of height with half-circles at both ends.
{ type: "ramp", width, height, rises? }A right triangle whose bottom edge is centered on the position. rises is "right" (the default) or "left".
{ type: "polygon", points }A convex polygon. If the points aren't convex, Rapier uses their convex hull, the smallest convex shape around them. The drawing shows the hull that Rapier actually built.
{ type: "polyline", points }Connected line segments for terrain, such as the hills here. A polyline can be concave, but it has no inside, so it can't be dynamic.

Options

OptionDefaultDescription
x, yrequiredPosition, in meters.
angle0Rotation in radians, counterclockwise.
body"fixed""fixed" never moves, "dynamic" falls and collides, and "kinematic" moves only from code.
density1Mass per square meter. A heavier shape pushes lighter ones harder.
friction0.50 is ice and 1 is rubber.
restitution0Bounciness. 1 bounces back to the same height. When two surfaces touch, the bouncier one wins.
colorby body typeGray for fixed, orange for dynamic and blue for kinematic.

Methods: applyImpulse(x, y), applyTorqueImpulse(torque) to spin it, and getAngle().

The player on slopes

The player walks up and stands on slopes up to maxSlope, which defaults to 50°. It doesn't slide down them while standing still. Anything steeper counts as a wall: the player can't stand on it or jump up it, and with wall jump enabled, it can wall slide on it.
