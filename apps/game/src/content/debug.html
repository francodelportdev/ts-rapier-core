Debug renderer

Draws what the physics sees: every collider, body and sensor, even the invisible ones. Every demo on this site has a debug view switch, so you can look inside any of them.

  • ← → Move
  • Space Jump (×2)

Using it

game.debug.enabled = true;   // or game.debug.toggle()

game.debug.colliders = true;   // outlines
game.debug.centers = true;     // a cross at each body's center
game.debug.velocities = true;  // an arrow on dynamic bodies

game.debug.getStats();  // { bodies, colliders, sensors, sleeping }

It reads the colliders straight from Rapier, so it shows the real shapes, not the sprites. It respects the camera and is drawn over everything. getStats() works with the overlay off too.

What the colors mean

ColorMeaning
■ GrayFixed body.
■ BlueKinematic body, such as the player.
■ OrangeDynamic body, awake.
■ Dark orangeDynamic body, asleep: Rapier stopped simulating it until something touches it.
■ Green, dashedSensor.
■ PinkVelocity of a dynamic body. The arrow shows where it will be in 0.25 s.

The player's velocity isn't shown, because it moves through the character controller: use player.getVelocity(). Turn the overlay off in production: it's off by default.
