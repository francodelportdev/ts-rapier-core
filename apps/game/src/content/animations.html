Animations

Sprites replace the rectangles with images, and an animator plays their frames. Here, the character changes clip with its state: try running, jumping, dashing and sliding down the wall on the left.

How it works

  1. The sprite sheet

    await loadSpriteSheet("/hero.png", 32, 32) loads an image and cuts it into frames of 32×32 pixels, numbered left to right and top to bottom. With an image you already have, use new SpriteSheet(image, 32, 32).

  2. The animator

    new Animator(clips, "idle") plays named clips. It has play(name), pause(), resume() and speed, and it runs with the physics steps.

  3. The sprite

    new Sprite({ sheet, animator, width, height }) sets the size on screen in meters. entity.setSprite(sprite) shows it instead of the entity's draw(), on any entity. The physics doesn't change: the collider stays the same whatever the image's size, and the sprite turns with the body.

  4. The player

    animatePlayer(player, sprite) plays the clip named like each state and mirrors the sprite to the facing direction. A state without a clip plays "idle". Different names? animatePlayer(player, sprite, { run: "walk" }).

Clips

const animator = new Animator({
  idle:   { frames: [0, 1, 2, 3], fps: 4 },
  attack: { frames: [4, 5, 6], fps: 12, loop: false, next: "idle" },
}, "idle");
FieldDefaultDescription
framesrequiredFrame numbers in the sheet, in playing order.
fpsrequiredFrames per second.
looptrueStart over at the end.
nextnoneClip to play when a non-looping clip ends.

Events: change, end and frame, which is handy for footstep sounds. play() with the clip already playing does nothing, unless you pass { restart: true }.

Sprite options

OptionDefaultDescription
sheet, width, heightrequiredThe sheet, and the size in meters.
animatornoneChooses the frame.
frame0The frame to show without an animator.
offsetX, offsetY0Moves the image from the body's center, in meters.
flipXfalseMirrors the image. It can be a function.
smoothfalseBlends pixels when scaling. Keep it off for pixel art.
