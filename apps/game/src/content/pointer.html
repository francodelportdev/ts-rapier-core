Mouse & touch

Mouse and fingers work the same way, with positions already in meters. Click or tap to drop a ball, drag a box, and use the on-screen buttons to move. Every demo on this site shows those buttons on a touch screen.

  • Click or tap Drop a ball
  • Drag Move a box
  • ← → ↑ On-screen buttons or keyboard

game.pointer

game.pointer.on("down", ({ worldX, worldY }) => spawn(worldX, worldY));

game.pointer.world;        // { x, y } in meters, following the camera
game.pointer.x;            // in canvas pixels
game.pointer.isDown;       // any button or finger
game.pointer.wasPressed(); // for one physics step: handy in update()
game.pointer.getActive();  // every finger on the canvas
MemberDescription
x, y, worldThe last position, in pixels and in meters.
isDownTrue while anything is pressing the canvas.
wasPressed(), wasReleased()True during the physics step after a press or release.
getActive()A list of { id, type, x, y, worldX, worldY }, one per finger.
on, once, offEvents down, move and up, with that same data.

Positions account for CSS scaling and the camera. Dragging outside the canvas keeps working. A finger on the canvas controls the game, so it doesn't scroll the page: scroll from outside it.

game.touch

game.touch.enabled = true;  // appears on the first touch

game.touch.setButtons([
  { press: "left", label: "←", x: 42, y: -42 },
  { press: "jump", label: "↑", x: -42, y: -42, radius: 40 },
]);

On-screen buttons press actions, such as "jump", or a key code, so Player works unchanged. Read them with Input.getInstance().isAction("jump"). Several fingers work at once, and a finger can slide between buttons. Positions are in canvas pixels, and negative values count from the right or bottom edge. The default buttons are ←, → and jump, and addButton() adds more. On a canvas shrunk by CSS, as on a phone, buttons grow to keep their size on screen. With alwaysVisible, they're shown from the start, and a mouse can press them too.

Input.getInstance().press(name) and release(name) hold an action or a key from code, for your own controls.
